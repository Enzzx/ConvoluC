# ConvoluC (dll version)
This version of [ConvoluC](https://github.com/Enzzx/ConvoluC) serves as a lib to be used on [ConvoluCam](https://github.com/Enzzx/ConvoluCam) project. It has slightly changes from main branch, changing some functions and deleting the main file, as long the needed funcs are being exposed on the dll (defineMatrix and convoluteImg).

## Setup
`make` to create .dll

`make clean` to clean
